# Lotus Lantern PC

Управление LED-лентой **ELK-BLEDOM** (та, что работает с приложением Lotus Lantern) с компьютера на Windows через встроенный Bluetooth.
Программа живёт в трее; по щелчку из-за панели задач выезжает стеклянная панель.

- включение и выключение, яркость;
- цвета (жёлтый первым), полоса оттенков и свой цвет;
- белый свет от тёплого до холодного;
- 22 эффекта лампы со скоростью;
- автозапуск вместе с Windows (через Планировщик заданий) и меню в трее.

## Установка

1. Скачайте `LotusLanternPC.exe` из [Releases](../../releases).
2. Положите его в постоянную папку и запустите. Лампа найдётся сама.
3. Автозапуск включается в меню значка в трее: «Запускать вместе с Windows».

Нужны Windows 10/11 с Bluetooth LE и WebView2 Runtime (в Windows 11 он уже есть).

## Сборка из исходников

Нужен Python 3.12+.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт создаст `.venv`, поставит зависимости и соберёт `LotusLanternPC.exe` рядом с кодом.
Запуск без сборки: `.venv\Scripts\python lotus_lantern_pc.py` (с ключом `--tray` — сразу в трей).

## Устройство

| Файл | Что внутри |
|---|---|
| `protocol.py` | BLE-протокол ламп: команды `7E … EF` в характеристику `FFF3`, шифрование для имён `ELK-*` |
| `lamp.py` | соединение с лампой в фоне, переподключение, очередь команд, сохранение настроек |
| `lotus_lantern_pc.py` | окно (pywebview + WebView2), анимация выезда, трей |
| `system.py` | значок, автозапуск, журнал, защита от второй копии |
| `ui/panel.html` | интерфейс панели |

Настройки и журнал: `%APPDATA%\LotusLanternPC\` (`config.json`, `app.log`).
